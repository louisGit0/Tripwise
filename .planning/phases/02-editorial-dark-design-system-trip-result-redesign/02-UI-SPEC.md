## Typography

> **REVISED post-checkpoint (D-11, 2026-06-02):** The editorial SERIF display (Instrument Serif)
> below was implemented, reviewed live, and **dropped** at the user's request. Titles/headings use
> **Space Grotesk bold (700)** — there is NO serif family. The `--text-display` size token stays;
> only the serif font-family was reverted. Read the size scale + 2-weight rules below as still
> authoritative; ignore the "Instrument Serif"/serif rows (now Space Grotesk). Phase 3 must not
> reintroduce a serif display.

PD-2: editorial serif display + Space Grotesk UI + JetBrains Mono numerics. **2 families + mono.**
Words use serif/sans; **all numbers use mono** (PD-2). Serif is reserved for the `display` tier
only (≥24px) — never small labels (editorial serifs read as weak at small sizes).

**Disciplined scale: exactly 4 sizes + exactly 2 weights (400 regular, 700 bold).** Hierarchy is
carried by size + family + the 2 weights — not by a long weight ramp. Section structure uses the
`eyebrow` style (caption size, 700, uppercase, tracked) rather than a separate mid heading tier —
a deliberate editorial choice that removes the redundant 16/18px tiers.

**4 size tokens:**

| Token | Value | Role |
|-------|-------|------|
| `--text-hero` | `clamp(64px, 14vw, 112px)` | Hero cost figure only |
| `--text-display` | `clamp(24px, 5vw, 40px)` | Serif route/page title (h1); large section headings |
| `--text-body` | `14px` | Body copy, inline numerics, breakdown labels/values |
| `--text-caption` | `11px` | Eyebrow labels, captions, meta |

**2 weights only:** `400` (regular) and `700` (bold). No `500`, no `600`.

| Role | Family | Size token | Weight | Line Height | Tracking |
|------|--------|------------|--------|-------------|----------|
| Hero numeric (cost €) | JetBrains Mono | `--text-hero` | 700 | 1.0 | -0.02em, `tabular-nums` |
| Display title (route/page h1) | Instrument Serif | `--text-display` | 400 | 1.05 | 0 |
| Section heading (h2) | Instrument Serif | `--text-display` (low end ~24px) | 400 | 1.1 | 0 |
| Eyebrow / label / section kicker | Space Grotesk | `--text-caption` | 700 | 1.2 | 0.14em, UPPERCASE |
| Body | Space Grotesk | `--text-body` | 400 | 1.5 | 0 |
| Numeric (inline figures) | JetBrains Mono | `--text-body` | 400 | 1.4 | 0, `tabular-nums` |
| Caption / meta | Space Grotesk | `--text-caption` | 400 | 1.4 | 0 |

Emphasis within body uses weight `700` (not a larger size). Existing pages' `16px`/`18px` usages
map to `--text-body` (14px) or `--text-display` for true headings — Phase 3 migrates them.

**next/font wiring (`web/src/app/layout.tsx`) — 2 weights system-wide:**
- Add `Instrument_Serif` → `weight: ['400']`, `style: ['normal','italic']`, `variable: '--font-serif'`,
  `display: 'swap'`, `preload: true`, latin subset. (Only 400 exists → it IS the critical weight.)
- Space Grotesk: `weight: ['400','700']` (drop 500 + 600), keep `--font-display`, `display: 'swap'`.
- JetBrains Mono: `weight: ['400','700']` (drop 500 + 600), `--font-mono`, `display: 'swap'`.
- Add `${instrumentSerif.variable}` to the `<body>` className.

**Tailwind (`tailwind.config.ts`):** add `fontFamily.serif: ['var(--font-serif)','Georgia','serif']`;
add `fontSize.{hero,display,body,caption}` mapped to the 4 tokens above. Keep `display`/`sans` →
`var(--font-display)` (Space Grotesk) for back-compat with existing pages.

**globals.css change:** `h1` (display title) → `font-family: var(--font-serif)`, `font-weight: 400`,
`letter-spacing: 0`, `line-height: 1.05`. `h2` → serif 400 at `--text-display` low end. `body` stays
`var(--font-display)` 400. Perf budget honored: swap on all, preload only the critical weight,
≤2 families + mono, **exactly 2 weights**.

## Data-Viz Bar Primitive (DES-01 / DES-02 / PD-3)

A single reusable primitive `DataBar` lives in `web/src/components/ui/DataBar.tsx`. It is
**token-driven** (colors come from `--c-*` CSS vars, never hard-coded Tailwind palette classes)
and serves both result-page bar use cases. Not ad-hoc.

### Structure & tokens

- Track: `bg-carbon-surface2`, `rounded-full`, `overflow-hidden`.
- Fill: absolutely-contained child, `rounded-full`, color via inline `style={{ background: 'var(--c-ev)' }}`
  (or the relevant energy/toll var). Muted (non-current) fills use inline `style={{ opacity: 0.45 }}`.
- Heights: `sm` = 6px (`h-1.5`), `md` = 10px (`h-2.5`). Default `md`.
- Width = `(value / max) * 100%`.

### Variant A — Breakdown bar (Énergie vs Péage) — NEW on result page

PD-3: a single **segmented** horizontal bar showing the two cost components of the grand total.
- One track, two adjacent fills: Énergie segment (`var(--c-ev|--c-fuel-gas|--c-fuel-die)` by the
  trip's energy type) sized to `energyCost / total`; Péage segment (`var(--c-toll)`) sized to
  `tollCost / total`. Segments sit flush; outer corners `rounded-full`.
- Legend row beneath: two label+value pairs, each prefixed by a 6px color dot matching its segment
  (`Énergie · 12,40 €` / `Péage · 8,30 €`). The toll value carries the existing réel/≈ estimé
  `Pill` + `Tooltip` (reuse `result/page.tsx:157-169`).
- **Hide the Péage segment + legend entirely when `tollCost === 0`** (preserves D-04 hide-when-0).
  When no toll, render a single full-width energy bar.

### Variant B — Comparison bars (gas / diesel / ev / gpl)

Replaces the existing ad-hoc comparison block (`result/page.tsx:272-321`). One `DataBar` row per
`EnergyComparison`, sorted cheapest-first (current behavior kept):
- Row top line: category `label` (left) + `totalCost` formatted EUR in JetBrains Mono (right).
- Bar: width `totalCost / maxCost`, fill color = energy token by `category`
  (`ev→--c-ev`, `gas→--c-fuel-gas`, `diesel→--c-fuel-die`, `gpl→--c-fuel-gpl`).
- `isCurrent` row: fill `opacity: 1`, label `text-carbon-ink`, `← actuel` marker in `--c-accent`.
  Non-current rows: fill `opacity: 0.45`, label `text-carbon-ink2`.
- Sub-caption (mono, muted): `{consumption} {unit} · {unitPrice} €/{unit}` (kept).

### Reveal / reduced-motion behavior

- On mount, each fill animates width 0 → target via **`transform: scaleX()`** (`transform-origin: left`,
  compositor-friendly, no document reflow), 600ms `cubic-bezier(0.16,1,0.3,1)`.
- Comparison rows + breakdown legend use the staggered reveal (below).
- `prefers-reduced-motion: reduce` → fills render at final `scaleX(1)` immediately, no transition.

## Motion (DES-04 / PD-4)

All motion is **transform/opacity only**, within CWV (no layout shift), gated by a new
`useReducedMotion()` hook in `web/src/hooks/useReducedMotion.ts` (`matchMedia('(prefers-reduced-motion: reduce)')`,
SSR-safe default `false`, subscribes to change). No prefers-reduced-motion infra exists today — this is net-new.

### Animated hero counter (`useCountUp`)

- New hook `web/src/hooks/useCountUp.ts`: `requestAnimationFrame`, ease `easeOutCubic`, duration
  **700ms**, 0 → target (re-runs when `passengers` changes the per-person total).
- Renders into the hero figure in **JetBrains Mono `tabular-nums`** with fixed 2 decimals so digit
  width is constant → **zero CLS** (the figure box never reflows mid-count).
- Reduced-motion → set final value on first paint, single render, no rAF loop.
- A11y: the animating span is `aria-hidden`; a visually-hidden `sr-only` sibling holds the final
  formatted total for screen readers (no `aria-live` chatter).

### Staggered reveal

- Targets: hero metric tiles, breakdown legend items, comparison rows.
- Technique: CSS keyframe `reveal { from { opacity:0; transform: translateY(8px) } to { opacity:1; transform:none } }`
  applied per item with inline `animation-delay: ${Math.min(index*60, 300)}ms`, 360ms `ease-out`,
  `animation-fill-mode: both`.
- No CLS: items occupy their final layout slot immediately (only opacity + `translateY(8px)` animate,
  and transform does not reflow siblings).
- Reduced-motion → no `reveal` animation class (render final state).

### Interaction transitions

- Default transition for hover/press: `transition-all` ≤180ms (matches existing CTAButton/`html`).
- Theme toggle keeps the existing 180ms `background-color/color` transition.

## Accessibility

- **Contrast (dark):** ink ~14:1, ink2 ~9:1, muted `#8a8173` ~4.8:1 (AA for small text — fixed from
  failing `#7a7163`). Accent `#4d8bff` on `--c-bg` ≥ 4.5:1 for ≥18px / non-text use. Energy fills
  are decorative-with-label: **never color-only** — every bar pairs with a text label + € value.
- **Reduced-motion:** `useReducedMotion()` disables the counter (final value instant), the staggered
  reveal, the bar scaleX fill, and the skeleton pulse.
- **Focus-visible:** standardized accent ring + 2px offset on every interactive element.
- **Counter SR:** animating span `aria-hidden`; `sr-only` sibling carries the final formatted total.
- **Hit targets:** stepper/icon buttons ≥ 32px; primary CTAs 44px (`h-11`).
- **CWV:** transform/opacity only; tabular-nums + fixed decimals → no CLS on the counting figure;
  bars use `transform: scaleX` (no reflow); fonts `display: swap`, critical serif weight preloaded.
