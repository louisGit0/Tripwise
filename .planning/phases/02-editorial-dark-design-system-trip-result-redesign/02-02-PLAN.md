  <behavior>

    - Re-runs the animation from 0 to the new target whenever the target changes (e.g. per-person total when passengers change).
    - When `useReducedMotion()` is true, returns the final target value immediately with no rAF loop (single render path).
    - Cancels any in-flight rAF on unmount or when the target changes (no leaked frames).
  </behavior>
  <action>
    Create a client hook `useCountUp(target: number, durationMs = 700): number`. Import and call
    `useReducedMotion()`. When reduced motion is true, set/return `target` directly (no animation loop).
    Otherwise drive a `requestAnimationFrame` loop: compute elapsed time, normalize to `t = min(elapsed/durationMs, 1)`,
    apply easeOutCubic (`1 - Math.pow(1 - t, 3)`), set state to `target * eased`, and stop at `t === 1` with the
    exact target. Restart the loop in a `useEffect` keyed on `target` (and duration); store the rAF id and
    `cancelAnimationFrame` it in the effect cleanup. Return the current numeric value (formatting is the caller's job).
    Export as a named export. No layout reads/writes — value only. No `console.log`.
