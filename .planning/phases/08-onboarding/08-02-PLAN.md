carousel (RN Modal) that auto-shows once per user on first authenticated load, is dismissible, and

on demand, with zero backend (a client-side per-user "seen" flag in expo-secure-store).

onboarding strings, the auto-trigger mounted in the tabs layout, and a "Revoir le tutoriel" entry

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| expo-secure-store | client-only per-user "seen" boolean keyed by user id |
| client → /auth/me | reads the already-authenticated user id (no new endpoint, JWT auto-injected by the axios client) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-02-01 | Information Disclosure | SecureStore seen flag keyed by userId | accept | A non-sensitive boolean; the user id is already in the user's own JWT; stored encrypted in SecureStore on the user's own device. No secret, no PII beyond the user's own id. |
| T-08-02-02 | Tampering | local flag cleared/forged | accept | Worst case the tour shows again or never — cosmetic only, no security or data impact. |
| T-08-02-03 | Spoofing/Elevation | DeviceEventEmitter replay event | accept | The event only opens a read-only UI overlay; no privileged action, no payload. App-local emitter (not cross-process). |
| T-08-02-SC | Tampering | npm installs | mitigate | No new dependency (RN Modal + DeviceEventEmitter + expo-secure-store are already present); if any install is proposed, stop — none is required. |
</threat_model>
