<objective>
Generalize the single-source ADEME sync into the multi-source merge orchestrator: iterate the adapters in precedence order (ADEME=0 first, EPA=10 second) into a first-writer-wins Map keyed by the uppercased canonical key so ADEME wins on overlap and EPA only fills gaps, then batch-upsert with `ON CONFLICT (brand, model, fuel_type)` (ADEME `DO UPDATE`, EPA `DO NOTHING`). The result is idempotent and extensible — a 3rd adapter drops into the array with no change to the merge, schema, or upsert.

Purpose: CAT-03 (dedup + ADEME-precedence merge, no cross-source dupes — PD4-1), CAT-05 (idempotent + extensible). Consumes plan 04-02 adapters + plan 04-01 schema.
Output: refactored `vehicle-sync.service.ts` + `catalog-merge.spec.ts`.
</objective>
