## Phase Goal

**As a** driver adding a vehicle to my garage, **I want to** search a far larger multi-source catalog that loads instantly even at thousands of models, **so that** I can find and select my actual car (not just the ~266 ADEME baseline) and get an accurate trip cost.

<objective>
Convert the garage showroom from a client load-all (it currently fetches up to 3000 rows into the browser via parallel pages) to a server-side, debounced, paginated search against the plan 04-03 API — while keeping every Phase 3 editorial-dark visual exactly as-is. This is the user-observable slice of the phase: the showroom that searches thousands of models fast.

Purpose: CAT-06 (server-side search + pagination, no client load-all, brand grouping preserved, fast on web). Data-layer-only rework; reuses the API mobile/Phase 5 consume.
Output: server-driven `garage/add/page.tsx` + a `source` field on the web `VehicleModel` type.
</objective>
