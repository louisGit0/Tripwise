## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-03-01 | Information disclosure | CARIMAGES_API_KEY | mitigate | The app never sees the key — it calls OUR endpoint (07-01) returning only `{ imageUrl }`. No CarImages key in the mobile bundle. |
| T-07-03-02 | Tampering | rendering the returned imageUrl | mitigate | The URL is used ONLY as an `<Image source={{ uri }}>` (no code execution); `onError`→placeholder handles a bad/dead URL; 07-01 validates `https://`. |
| T-07-03-03 | Denial of service (quota) | per-card image fetches | mitigate | 07-01 caches hits+misses (30-day TTL); SectionList paginates (limit 30) — repeated/identical lookups are cache-served. |
| T-07-03-04 | Spoofing / token | catalog + image calls | mitigate | `client` auto-injects the JWT; 401 → deleteToken (existing interceptor). |
| T-07-03-SC | Tampering | npm/expo installs | mitigate | No new dependency (RN built-in `Image` + existing atoms/axios); package-legitimacy gate N/A. |
