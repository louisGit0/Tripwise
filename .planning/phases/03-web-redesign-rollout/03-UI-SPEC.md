# Phase 3 — UI Design Contract (Web Redesign Rollout)

> **APPLICATION spec, not a new design system.** The editorial-dark language is LOCKED in Phase 2
> (`02-UI-SPEC.md` + `web/src/app/globals.css` + `web/tailwind.config.ts`). This contract specifies
> (1) the **atom normalization** to the 400/700 weight + token-color + standardized-focus contract,
> and (2) the **per-screen application** (composition + which primitives each screen uses) so the
> planner/executors make no ad-hoc decisions. Generated by gsd-ui-researcher; verified by gsd-ui-checker.
>
> **Do NOT re-decide** tokens, type scale, fonts, or motion. Reuse the locked system. The checker
> enforces ≤4 sizes / ≤2 weights and WILL BLOCK a serif display (D-11) or any 3rd weight (500/600/800).

## Typography

Inherited from Phase 2 (LOCKED). **4 size tokens, exactly 2 weights (400 / 700).** No 500, no 600, no 800.
Hierarchy = size × family × the 2 weights. `globals.css` already sets `h1`–`h6` → Space Grotesk **700**.

| Role | Family | Size token (raw equiv.) | Weight | Notes |
|------|--------|-------------------------|--------|-------|
| Hero numeric (cost €) | JetBrains Mono | `text-hero` `clamp(64,14vw,112)` | 700 | `tabular-nums`, only on a calc/result hero figure |
| Page / section title (h1/h2) | Space Grotesk | `text-display` `clamp(24,5vw,40)` | 700 | Migrate raw `text-2xl/4xl/5xl` titles → `text-display`; inherit 700 from globals |
| Eyebrow / kicker / label | Space Grotesk | `text-caption` (`text-[10px]`/`text-[11px]`) | 700 | UPPERCASE, `tracking-eye-wide` (`Eyebrow` atom) |
| Body | Space Grotesk | `text-body` (`text-sm`/14px) | 400 | Default copy, breakdown labels/values |
| Inline numeric | JetBrains Mono | `text-body` | 400 (700 for emphasis figures) | `tabular-nums` |
| Caption / meta | Space Grotesk | `text-caption` (`text-[11px]`) | 400 | muted meta lines |

**Raw-size → token mapping (consolidation rule for executors):**

| Current raw class (sprawl) | Map to |
|----------------------------|--------|
| `text-4xl` / `text-5xl` / `text-3xl` / `text-2xl` on a **title** | `text-display` |
| `text-3xl` / `text-5xl` on a **KPI/data figure** | `text-display` (KPICell `md`) / `text-hero` (a single dominant figure only) |
| `text-base` / `text-sm` body | `text-body` (`text-sm`) |
| `text-xs` / `text-[11px]` / `text-[10px]` meta/eyebrow | `text-caption` |

**Weight migration (the core of PD3-1) — every occurrence below moves to 400 or 700:**
- `font-medium` (500) → `font-normal` (400) for body/labels/segments; → `font-bold` (700) only for primary CTA text.
- `font-semibold` (600) → `font-bold` (700) for titles/eyebrows/badges/emphasis.
- `font-extrabold` (800) on landing `<h1>` → `font-bold` (700) (or drop, inherit from globals h1).
- `font-bold` (700) → keep.

## Color

Inherited from Phase 2 (LOCKED — `globals.css` `:root`/`[data-theme]`). Do not change values. Dark-first; light derived.

| Role | Token | Usage |
|------|-------|-------|
| Dominant (60%) | `--c-bg` `#0e0c0a` | Page background, gutters, topbar wash |
| Secondary (30%) | `--c-surface` / `--c-surface2` / `--c-surface3` | Cards (`SectionCard`), inset tiles/tracks, hero plate / modal / tooltip |
| Accent (10%) | `--c-accent` `#4d8bff` | reserved list below |
| Destructive | `red-600` `#dc2626` | `danger` CTA variant only (delete vehicle, logout) |

**Accent `#4d8bff` reserved for (explicit — never "all interactive elements"):** primary CTA fill;
active SegmentedControl / filter-chip / source-toggle fill; the dashboard hero result figure accent
context; focus-visible rings; text selection; inline links (`text-carbon-accent`); the sidebar
active-item dot/text. Body text, card chrome, secondary buttons, and meta use `ink`/`ink2`/`muted`/
`surface*` — never accent.

**Energy palette is semantic data-viz only** (`--c-ev/--c-fuel-gas/--c-fuel-die/--c-fuel-gpl`,
`--c-toll`): appears ONLY in `DataBar` fills and `FuelBadge`. Never decorative chrome.

**Concrete-Tailwind-color exception (documented, allowed):** opacity modifiers do NOT work on
CSS-var colors (e.g. `bg-carbon-accent/10` is a no-op). Therefore **tinted/translucent state fills
and semantic status colors are allowed to use concrete Tailwind palette classes**, but ONLY in these
sanctioned places — they are NOT a license for ad-hoc theming:
- `Pill` (success/warning/danger/info), `FuelBadge`, delta badges → `emerald/amber/red/sky-400` + `/1x` tints (existing).
- Accent tints where a translucent accent wash is needed → `bg-blue-500/10`, `border-blue-500/20` (existing dashboard result chip, garage hover icons). Acceptable; do not invent new hues.
- **Energy fills must use `--c-*` tokens via `DataBar`** — never `bg-emerald/sky/violet` ad-hoc (the Phase-2 result-page cleanup; do not regress on dashboard).

**Color-correctness fix (ship in atom wave):** `CTAButton` focus ring uses `ring-blue-500/50`
(`#3b82f6`) which is **not** the accent (`#4d8bff`). Standardize to the accent ring (below).

## Interaction States (DES-03 — standardize across every screen)

**Canonical focus token (PD3-1) — apply to EVERY interactive element** (buttons, links-as-buttons,
inputs, selects, segmented controls, chips, icon buttons, list-row buttons):

```
focus:outline-none focus-visible:ring-2 focus-visible:ring-carbon-accent/50 focus-visible:ring-offset-2 focus-visible:ring-offset-carbon-bg
```

This is the exact string already used at `result/page.tsx:33`. Note: `/50` is ignored on the
CSS-var `carbon-accent` (renders full-opacity accent) — that is the accepted, consistent token form
per PD3-1 ("consistent focus-visible ring `ring-carbon-accent/50`"). Replace all `ring-blue-500/50`,
`ring-blue-500/30`, and `focus:ring-carbon-accent focus:ring-offset-0` (Input/Select/Autocomplete)
with this single token.

| Element | Rest | Hover | Focus-visible | Active | Disabled |
|---------|------|-------|---------------|--------|----------|
| Primary CTA (`accent`) | `bg-carbon-accent` white, **700** | `brightness-110` | canonical ring | `brightness-90` | `opacity-50` |
| Surface CTA | `bg-carbon-surface2` ink + hairline | `bg-carbon-faint` | canonical ring | `bg-carbon-hairline` | `opacity-50` |
| Ghost CTA | `text-carbon-ink2` | `text-carbon-ink` + `bg-carbon-faint` | canonical ring | `bg-carbon-hairline` | `opacity-50` |
| Danger CTA | `bg-red-600` white | `bg-red-500` | red ring (`ring-red-500/40`) | `bg-red-700` | `opacity-50` |
| Input / Select | `bg-carbon-surface` + hairline | — | canonical ring + `border-carbon-accent` | — | `opacity-50` |
| Segmented seg / filter chip / source toggle | inactive: `text-carbon-muted` | `text-carbon-ink2` + `bg-carbon-faint` | canonical ring | active: `bg-carbon-accent text-white` | `opacity-40` |
| List-row button (trips/favorites/garage) | `bg-transparent` | `bg-carbon-surface2` | canonical ring | — | — |
| Icon button (edit/delete/star/collapse) | `text-carbon-muted` 32px | `text-carbon-ink` (or semantic) + faint/tint bg | canonical ring | — | `opacity-40` |

**Weight stays constant across segmented/toggle states** (active vs inactive use color/bg, never a
weight change) — prevents sub-pixel reflow (CWV).
