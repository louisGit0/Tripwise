<objective>
Add a JWT-guarded `PATCH /users/me` endpoint so a user can change their pseudo (`display_name`).
The `display_name` column already exists on the `User` entity — **no migration**. The endpoint
validates, trims, and length-bounds the input, updates only the authenticated user, and returns
the updated profile in the same shape as `GET /auth/me`. This is the backend half of POL-03 and is
blocking for the web + mobile Settings UI (Wave 2).

Purpose: Persist pseudo edits server-side, safely (own user only, bounded input).
Output: `UpdateProfileDto`, `UsersService.updateProfile`, `UsersController` PATCH route, e2e spec.
</objective>
