# Phase 1.1: Route-aware free toll estimator - Research

**Researched:** 2026-06-01
**Domain:** NestJS service-layer change — route classification from Mapbox Directions `steps` + French autoroute €/km rate model (fully free, no paid API)
**Confidence:** HIGH (codebase verified by reading; Mapbox `ref` field confirmed via official docs; FR toll rates + free list confirmed via multiple current sources)

## Summary

Phase 1 shipped a provider-agnostic `TollService.computeTollCost(coordinates, distanceKm, durationSeconds)` with a dormant TollGuru branch, a 30-day SHA-1 cache, a never-throw contract, and a crude **speed-based** flat heuristic (`estimateFrenchTolls`) that is the production value (D-07, no paid key). This phase replaces only that heuristic with a **route-aware free estimate**: detect the autoroute kilometres actually on the route and multiply by a French average €/km.

The clean, fully-free detection technique is **Mapbox Directions `steps=true`**, which exposes a per-step `ref` field (the road designation, e.g. `"A 6"`) and a per-step `distance` (metres) — confirmed in the official Mapbox docs `[CITED: docs.mapbox.com/api/navigation/directions]`. Today `MapboxService.getDirections` requests `steps=false`; the minimal change is to flip it to `true`, capture `routes[].legs[].steps[].{distance,ref,name}`, and thread a flattened `steps` array into a new **optional 4th parameter** of `computeTollCost`. `TollService` then sums the distance of steps whose `ref` matches an autoroute (`A\d+`) minus a free-autoroute exclusion list, and multiplies by `~0.09 €/km`. When no steps are supplied (e.g. the distance-only client mode, or any caller that doesn't pass them), it falls back to the existing speed heuristic — so the contract and every current call site keep working.

**Primary recommendation:** Flip Mapbox to `steps=true`, surface `steps` on `DirectionsResult`, add an **optional** `steps` arg to `computeTollCost` (signature stays backward-compatible → honours LD-2), and implement a private `classifyTolledKm(steps)` in `TollService` using a `FREE_AUTOROUTES` set + a `NATIONAL_AVG_RATE_PER_KM = 0.09` constant (the existing `TOLL_RATE_PER_KM` value, now sourced). Estimate = `tolledKm × 0.09`, always `isEstimate: true`. No new dependency, no schema change, no UI change.

### Recommended computation formula (concrete)

```
tolledKm   = Σ  step.distance(km)   for each step where
                 - step.ref matches  /\bA\s?-?\d+/i      (a French autoroute designation)
                 - the parsed A-number is NOT in FREE_AUTOROUTES
cost(€)    = round2( tolledKm × NATIONAL_AVG_RATE_PER_KM )      // NATIONAL_AVG_RATE_PER_KM = 0.09
isEstimate = true   (always — LD-6)

Edge cases:
  - steps empty/undefined         → fall back to existing speed heuristic (graceful degradation)
  - tolledKm === 0 (no autoroute) → { cost: 0,  isEstimate: true }   // success criterion #2
  - distanceKm < 5 with no steps  → null (unchanged guard)
```

> **Calibration note (document in code):** The rate `0.09 €/km` is applied to **gross matched-autoroute km** (the km Mapbox labels with an `A` ref, minus fully-free autoroutes). This deliberately absorbs the small free urban approaches that Mapbox still labels e.g. `"A 6"` (free section before the first Paris barrier), because barrier-to-barrier tolled km is not derivable for free. Calibration anchor: Paris→Lyon is almost entirely `A 6`/`A 7` (~450 matched km) → `450 × 0.09 = 40.50 €`, against a real class-1 toll of **40.90 €** (1 Feb 2025) — i.e. the gross-km × 0.09 model lands inside the €30–45 success band by design.

### Mapbox change (exact)

**File:** `backend/src/mapbox/mapbox.service.ts`

1. Flip the param (line ~111): `steps: 'false'` → `steps: 'true'`.
2. Extend the raw response interface to capture legs/steps:
```ts
interface MapboxDirectionsResponse {
  code: string;
  message?: string;
  routes: Array<{
    distance: number;
    duration: number;
    geometry: { type: string; coordinates: [number, number][] };
    legs: Array<{
      steps: Array<{ distance: number; ref?: string; name?: string }>;  // NEW
    }>;
  }>;
  waypoints: Array<{ name: string; location: [number, number] }>;
}
```
3. Add a public `RouteStep` type + a `steps` field on `DirectionsResult`:
```ts
export interface RouteStep {
  distanceMeters: number;     // step.distance (metres)
  ref: string | null;         // e.g. "A 6", "A6;E 15", or null when absent
  name: string | null;        // road name fallback (rarely needed)
}
// DirectionsResult gains:  steps: RouteStep[];
```
4. Flatten all legs’ steps when building the return value:
```ts
const steps: RouteStep[] = (route.legs ?? []).flatMap((leg) =>
  (leg.steps ?? []).map((s) => ({
    distanceMeters: s.distance ?? 0,
    ref: s.ref ?? null,
    name: s.name ?? null,
  })),
);
```

**Response inflation:** `steps=true` adds the `legs[].steps[]` array (~50–150 steps for Paris→Lyon, each carrying its own small geometry that we discard). This roughly 1.5–2.5× the **wire** size of this single backend→Mapbox call; we keep only `{distance, ref, name}` so retained memory is negligible. It is one Directions call (no extra request), still within the existing quota. Mapbox offers no flag to suppress per-step geometry, so accept the transfer inflation. `overview=full` route geometry is unaffected — the existing `geometry` field and all current behaviour are preserved.

### Pattern: graceful degradation when steps are absent
**What:** `computeTollCost`/`estimateFrenchTolls` accept `steps` as **optional**. If `steps?.length` is truthy → route-aware path; otherwise → existing speed heuristic. **Why:** the distance-only dashboard mode and any future caller that lacks steps must still get a number; never break the contract. **Example:**
```ts
private estimateFrenchTolls(
  distanceKm: number,
  durationSeconds: number,
  steps?: RouteStep[],
): number | null {
  if (steps && steps.length > 0) {
    const tolledKm = this.classifyTolledKm(steps);
    return round2(tolledKm * NATIONAL_AVG_RATE_PER_KM);   // 0 km → 0 €, still isEstimate:true upstream
  }
  // ── existing speed-based heuristic (unchanged) ──
  if (durationSeconds === 0 || distanceKm < 5) return null;
  /* ...existing avgSpeed fraction logic... */
}
```

### Pattern: defensive ref classification (never-throw)
```ts
/** Parses every A-number in a Mapbox step `ref` ("A 6;E 15" → [6]). */
function parseAutorouteNumbers(ref: string | null): number[] {
  if (!ref) return [];
  const out: number[] = [];
  for (const token of ref.split(';')) {
    const m = /^\s*A\s?-?\s?(\d+)/i.exec(token.trim());   // matches "A6", "A 6", "A-6"
    if (m) out.push(Number(m[1]));
  }
  return out;
}

private classifyTolledKm(steps: RouteStep[]): number {
  let metres = 0;
  for (const step of steps) {
    const aNumbers = parseAutorouteNumbers(step.ref);
    if (aNumbers.length === 0) continue;                  // not an autoroute step
    const isTolled = aNumbers.some((n) => !FREE_AUTOROUTES.has(n));
    if (isTolled) metres += step.distanceMeters ?? 0;
  }
  return metres / 1000;
}
```
Guards: null `ref`, missing `distanceMeters`, malformed strings all yield 0 contribution — no throw (preserves the never-throw contract, LD-2).

### Anti-Patterns to Avoid
- **Changing the `computeTollCost` signature in a breaking way** — add `steps?` as an *optional trailing* arg only; do not reorder/rename existing params (LD-2).
- **Touching the dormant TollGuru branch, the cache, or the TollGuru constants** — out of scope (LD-2). The change lives in `estimateFrenchTolls` + a small classifier + new constants.
- **Adding Overpass/OSM runtime calls** — FALLBACK technique only; not needed (LD-4).
- **Flipping `isEstimate` to false for a route-aware estimate** — it is still an estimate (LD-6); always `true`.
- **Summing every `A`-ref step blindly** — must subtract `FREE_AUTOROUTES` or toll-free motorways (A75/A84/A20…) get over-charged.
- **Hard-failing when Mapbox omits `legs`/`steps`** — fall back to the speed heuristic (graceful degradation).

## Rate Model — French autoroute €/km constants (LD-5)

> **Source of truth caveat:** French concessionaires publish **barrier-to-barrier grids**, not a single €/km per network. The per-network €/km figures below are *derived averages* widely cited by aggregators and are **`[ASSUMED]`** at the operator level. The **defensible workhorse is the national average ~0.09–0.12 €/km** `[CITED: ASFA, cartecarburant.leclerc, lesfurets]`; `0.09` is recommended as the primary constant (it matches the lower bound, matches the Paris→Lyon anchor on gross km, and equals the value already in the codebase).

### Optional per-autoroute override (discretionary — keep minimal, YAGNI)
The national average already meets all success criteria. If finer accuracy is wanted later, a small `AUTOROUTE_RATE_OVERRIDES: Map<number, number>` keyed by A-number (the only granularity `ref` gives) can encode the few material deviations, e.g. `8 → 0.12` (Escota A8), defaulting to `NATIONAL_AVG_RATE_PER_KM`. **Recommendation: ship with the national average only**; add overrides only if a future test shows a Riviera route is materially off. (Per-operator rates can’t be applied directly because `ref` yields the A-number, not the operator; many autoroutes span multiple operators.)

  75, // A75 La Méridienne (Clermont-Ferrand→Béziers, ~340 km) — sauf viaduc Millau
  84, // A84 Caen↔Rennes (Estuaires) — entièrement gratuite
  20, // A20 L'Occitane Vierzon→Montauban (~270 km) — gratuite sur la section dominante
  35, // A35 Alsace (Bâle→Strasbourg→frontière DE)
  31, // A31 Lorraine — majoritairement gratuite
  33, // A33 (Nancy) — gratuite
  34, // A34 (Ardennes) — gratuite

## Common Pitfalls

### Pitfall 1: `ref` formatting variants ("A 6" vs "A6" vs "A 6;E 15")
**What goes wrong:** A naive `ref === 'A6'` check misses Mapbox’s spaced form `"A 6"` and the semicolon-joined European-route form `"A 6;E 15"`, so tolled km reads 0 and every autoroute trip estimates €0.
**Why:** Mapbox `ref` = "alphabetic network code, a space or hyphen, and a route number", semicolon-separated for multiple designations `[CITED: docs.mapbox.com]`.
**How to avoid:** Split on `;`, match each token with `/^\s*A\s?-?\s?(\d+)/i` (see `parseAutorouteNumbers`). Unit-test all four spellings.
**Warning signs:** Autoroute routes returning €0; a test with mocked `"A 6"` steps failing.

### Pitfall 2: Free urban approaches labelled with an autoroute `ref` inflate tolled km
**What goes wrong:** The free section of A6 before the first Paris barrier is still `ref:"A 6"` in steps. Summing all A6 km over-counts → over-charge.
**Why:** `ref` identifies the road, not whether that km is tolled.
**How to avoid:** Calibrate the rate to **gross matched-A-km** (recommended `0.09`), which lands Paris→Lyon at €40.50 vs €40.90 real — the over-count is absorbed by a slightly conservative rate. Do **not** chase per-barrier precision (out of scope).
**Warning signs:** Paris→Lyon estimate drifting above ~€46 (would indicate rate too high for the gross-km model).

### Pitfall 3: Over-charging fully-free autoroutes (A75/A84/A20…)
**What goes wrong:** Without the exclusion set, A75 (Clermont→Béziers) and A84 (Caen→Rennes) — toll-free — get charged at €0.09/km → tens of euros of phantom toll.
**How to avoid:** `FREE_AUTOROUTES` set (above); a step whose only A-number is free contributes 0 km.
**Warning signs:** A Caen→Rennes test returning a non-zero toll.

### Pitfall 4: Breaking the contract / never-throw guarantee (LD-2)
**What goes wrong:** Mapbox sometimes omits `legs`/`steps` (or a step lacks `ref`/`distance`); unguarded access throws and the toll path errors instead of degrading.
**How to avoid:** `steps` optional everywhere; `?? []`/`?? 0`/`?? null` guards; no-steps → speed heuristic; classifier never throws. Keep `computeTollCost`’s existing try/catch-free estimate path.
**Warning signs:** A 500 on `/trips/calculate` for an unusual route; an e2e test surfacing a thrown error from the toll branch.

### Pitfall 5: Distance-only client mode has no coordinates/steps
**What goes wrong:** The dashboard "Distance" mode computes client-side with no route → no steps. If the estimator assumed steps, it would return null/0 incorrectly.
**Why:** `computeTollCost` is only invoked server-side in `/trips/calculate` (which has steps); the distance-only mode does **not** call the backend toll path today. But future callers might pass no steps.
**How to avoid:** Optional `steps` + speed-heuristic fallback keeps any no-steps caller working. Document that distance-only mode is unaffected by this phase.
**Warning signs:** N/A today; guard is defensive for future call sites.

### Pitfall 6: Annual ~1 Feb tariff hike makes the rate drift
**What goes wrong:** Toll tariffs rise every 1 Feb (+0.86% 2026, +0.92% 2025, +3% 2024) `[CITED: Service-Public A16201, lesfurets]`; a hard-coded 0.09 slowly under-states over years.
**How to avoid:** Document the source + year in the constant’s JSDoc (LD-5); the drift is <1%/yr — immaterial for an estimate. Revisit the constant if the national average moves out of 0.09–0.12.
**Warning signs:** Estimates consistently ~5–10% below known real tolls after several years.

### TollService: route-aware estimate (constants + classifier + formula)
```ts
const NATIONAL_AVG_RATE_PER_KM = 0.09;                 // sourced — see Rate Model JSDoc
const FREE_AUTOROUTES = new Set<number>([75, 84, 20, 35, 31, 33, 34, 88, 16, 630, 620, 621]);

function parseAutorouteNumbers(ref: string | null): number[] {
  if (!ref) return [];
  const out: number[] = [];
  for (const token of ref.split(';')) {
    const m = /^\s*A\s?-?\s?(\d+)/i.exec(token.trim());
    if (m) out.push(Number(m[1]));
  }
  return out;
}

// inside TollService:
private classifyTolledKm(steps: RouteStep[]): number {
  let metres = 0;
  for (const step of steps) {
    const aNums = parseAutorouteNumbers(step.ref);
    if (aNums.length && aNums.some((n) => !FREE_AUTOROUTES.has(n))) {
      metres += step.distanceMeters ?? 0;
    }
  }
  return metres / 1000;
}

private estimateFrenchTolls(distanceKm: number, durationSeconds: number, steps?: RouteStep[]): number | null {
  if (steps?.length) {
    return round2(this.classifyTolledKm(steps) * NATIONAL_AVG_RATE_PER_KM);
  }
  // existing speed heuristic (unchanged fallback) ...
}
```
