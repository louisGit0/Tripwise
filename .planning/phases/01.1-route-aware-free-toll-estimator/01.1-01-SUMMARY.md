# Phase 01.1 Plan 01: Route-aware free toll estimator Summary

**Free route-aware toll estimate — sums Mapbox `steps[].ref` autoroute km minus a free-autoroute list × 0.09 €/km, behind the unchanged `TollService.computeTollCost` (additive optional `steps?`), still labelled "≈ estimé".**

## Accomplishments
- Replaced the crude flat speed-fraction heuristic with a route-aware estimate: tolled autoroute km (detected from Mapbox per-step `ref`) minus `FREE_AUTOROUTES` × `NATIONAL_AVG_RATE_PER_KM` (0.09). Paris→Lyon anchor (A6 250 km + A7 200 km = 450 km) → €40.50, inside the €30–45 band.
- No-autoroute and free-autoroute-only (A75/A84…) routes return 0; `ref` spelling variants ("A 6", "A6", "A-6", "A 6;E 15") all detected; malformed/missing `ref`/`distance` never throw.
- Mapbox `getDirections` now requests `steps=true` and surfaces a flattened `steps: RouteStep[]` (per-step distance + ref); `TripsService` threads `directions.steps` into the existing `Promise.all` toll call (no extra Mapbox fetch).
- Backward-compatible: the optional `steps?` param means no-steps callers fall back to the unchanged speed heuristic; the 30-day cache, never-throw contract, dormant TollGuru branch, and `TollResult` are untouched. No new dependency, no schema change, no UI change.

## Decisions Made
- National average rate only (no per-operator overrides) — KISS/YAGNI; `ref` only yields the A-number, not the operator, and the national average meets all success criteria.
- Renamed `TOLL_RATE_PER_KM` → `NATIONAL_AVG_RATE_PER_KM` (same 0.09) with sourced JSDoc (ASFA / Service-Public A16201 / Ulys), per LD-5.
- Empty `steps` array → graceful speed-heuristic fallback (guarded by `steps?.length`), consistent with the never-throw contract.
