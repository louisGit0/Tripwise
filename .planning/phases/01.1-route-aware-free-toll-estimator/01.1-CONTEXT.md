# Phase 1.1 Context — Route-aware free toll estimator

## Domain

Brownfield NestJS backend. Phase 1 shipped a provider-agnostic `TollService`
(`backend/src/toll/toll.service.ts`) with the signature
`computeTollCost(coordinates: [number,number][], distanceKm: number, durationSeconds: number): Promise<{ cost: number; isEstimate: boolean } | null>`,
a 30-day SHA-1 polyline cache, a never-throw silent-fallback contract, and a
`estimateFrenchTolls(distanceKm, durationSeconds)` **flat heuristic** as the fallback.
Phase 1 was re-scoped to estimate-primary (D-07): with no paid TollGuru key, the
heuristic IS the production value, always rendered "≈ estimé" on the web.

This phase replaces that crude flat heuristic with a **route-aware free estimate**.

## Locked Decisions

- **LD-1 — Free only, no card.** No paid API, no credit-card-gated service, no new
  paid dependency. (Research D-08: TollGuru = 14-day trial then $80+/mo; Google
  Routes = card + paid SKU beyond cap; FR open data has toll gates but no tariff grid.)
- **LD-2 — Same interface, contained change.** Keep `TollService.computeTollCost(...)`
  signature, the 30-day cache, and the never-throw contract. The change is internal
  to the heuristic/estimator. The precise TollGuru branch stays dormant and untouched
  (activates if a key is ever set).
- **LD-3 — Route-aware formula.** Estimate = (tolled autoroute km actually on the
  route) × (per-network average €/km). Replaces distance/duration-only flat math.
- **LD-4 — Tolled-km detection technique.** PREFER Mapbox Directions `steps=true`
  road `ref` (sum distances of `A\d+` autoroute steps) minus a free-autoroute
  exclusion list. This adds no external API (Mapbox already used) and is deterministic
  + unit-testable by mocking steps. Overpass `toll=yes` is the documented FALLBACK
  technique only if steps prove insufficient. Do NOT add an Overpass runtime
  dependency unless research shows Mapbox steps cannot identify autoroute km.
- **LD-5 — Per-network rates as named constants.** €/km rates per operator
  (Vinci/ASF, APRR, Sanef, others) live as documented module-level constants with a
  national-average fallback, sourced from research (annual hikes ~1 Feb — note the
  source + year in a comment). No live tariff fetch.
- **LD-6 — Still an estimate.** Result is always `isEstimate: true`. NO UI change —
  the web already shows "≈ estimé". Honesty preserved.
- **LD-7 — No schema change, no new endpoint.** Pure service-layer change + tests.

## Scope Fence

**In:** rewrite/replace `estimateFrenchTolls` (or its call path) inside `TollService`
to be route-aware; per-network rate table + free-autoroute list; obtain tolled-km
(via Mapbox steps — may require threading step/ref data into the estimator, or a
helper that classifies the route); unit tests for tolled-km detection, rate
application, no-autoroute=0, and the never-throw/null cases; keep all Phase 1 toll
tests green.

**Out:** precise/exact tolls (deferred, TOLL-01/03); any paid API; Google Routes;
building a full open-data tariff engine (a separate later option); UI changes;
schema/migration changes; mobile.

## Success Criteria (from ROADMAP)

1. Tolled-autoroute route → estimate scaled by tolled km × per-network €/km (not flat), `isEstimate=true`.
2. No-autoroute route → 0.
3. Paris→Lyon ≈ €30–45 band.
4. No paid dependency, no API key, no card-gated service.
5. Existing toll tests stay green; new unit tests cover detection + rate application + no-autoroute=0.

## Open Questions For Research

- Does the current `MapboxService.getDirections` request `steps`/`ref`? If not, what's
  the minimal, low-cost way to obtain per-step `ref` + distance (and does it inflate
  the response meaningfully)? Where does the tolled-km classification best live so
  `TollService` stays the owner of the estimate?
- Current per-network average €/km for FR class-1 (Vinci/ASF, APRR, Sanef) and a
  defensible national average — with sources.
- Which common autoroutes are toll-FREE (e.g., A75, A20 sections, A84, urban rings) —
  the exclusion list.
- A realistic expected toll band for Paris→Lyon (≈ A6) to anchor the test fixture.
